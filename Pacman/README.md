# Pac-Man (Java source)

This folder holds the Java Swing version of the game. The sources and sprites are in `src/`.

See the [main README](../README.md) for how to run and play the game.

To build by hand:

```sh
cd src
javac *.java
java App
```

In VS Code, open this folder with the *Extension Pack for Java* installed and run `App.java`.
VS Code writes its build output to `bin/`, which git ignores.
